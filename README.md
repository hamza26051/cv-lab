# Computer Vision Lab

### A hands-on record of learning to make images computable.

> Small experiments, lab notebooks, and visual-processing exercises — kept together because the iterations are part of the work.

---

## What this repository is

This is my working computer-vision lab notebook. It collects the practical exercises that helped me move from theory to implementation: opening an image, testing an operation, inspecting the result, and asking why it changed.

It is deliberately not polished into a framework. The notebooks preserve the process — including intermediate outputs and experiments — that feeds into my larger vision projects.

## How to explore it

1. Open the folder that interests you.
2. Launch the notebook in a Python environment with Jupyter available.
3. Run cells one at a time and compare the visual output with the code that produced it.

The value here is in the progression. These labs are the technical groundwork behind my more complete work in image pipelines, model experimentation, and AI product design.

## A note on reuse

The contents are coursework and experimentation material. Treat them as learning references rather than production-ready components, and verify any method against your own data and environment.
